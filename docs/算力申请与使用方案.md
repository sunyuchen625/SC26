- **商业 CPU**：官方算例位于 `/data/home/maorz/SolverChallenge26-TenProblems`，本队工作目录为 `/data/home/sunyc/solverchallenge26`。依赖路径为 `deps/hypre` 与 `deps/gnu-time/time`，工具链包含 GCC 11.3.0、OpenMPI 4.1.8、CMake 3.24.2、HYPRE 2.33.0 与 oneMKL 2022.0.0。
- **国产 GPU（SCNet）**：官方算例位于 `/public/share/ac3k88uz8y/SolverChallenge26-TenProblems`，工作目录为 `/public/home/travissun/sc26-hip-20261007`。加载 DTK `compiler/dtk/25.04.2`，基于 `gfx936` 与 `install-892588` 构建 HIP 版 HYPRE，构建脚本见 [scnet-hypre-build.sbatch](../scripts/scnet-hypre-build.sbatch)。
- **国产 CPU（LX2）**：经华为 Jumper 网页短信验证登录 Web RDP `10.15.83.48`，再通过 MobaXterm SSH 连接 `travissun@152.11.26.76:22`（平台绿区仅允许单向传入）。代理脚本位于 `/fs_real_a800/home/challenge26/env/set_proxy.sh`，赛题数据位于 `/fs_real_a800/home/challenge26`。详情参见 [LX2 环境附录](LX2_ENVIRONMENT_APPENDIX_2026-10-24.md)。

## 上机规范

- 登录节点仅用于代码编辑、作业准备与队列查询，所有编译与求解任务均通过调度器提交至计算节点执行。
- 内存约束按官方接口统计：第 1 题不超过 9 GB（CPU 参与计算时合计 CPU 与 GPU 内存，否则分别满足），第 9 题小于 100 GB。
- 参考手册见[海光 DCU 手册](../资料/SolverChallenge26_Hygon_DCU_Manual.pdf)与[商用 CPU 上机手册](../资料/盐城超算上机使用手册V0.3.1.pdf)。
